# Shoufeng Chen — Portfolio

Personal portfolio website built with **Quarto** and deployed with **GitHub Pages**.

**Live site:** https://shoufengchen.github.io

## Pages

- **About You** — professional introduction, interests, skills, and career direction
- **Projects** — selected analytics, cloud, finance, and research work
- **CV** — professional background with a downloadable PDF
- **Contact** — email, GitHub, and CV access

## Technology

- Quarto
- HTML / CSS
- GitHub Actions
- GitHub Pages

## Local preview

```bash
quarto preview
```

## Build

```bash
quarto render
```

The rendered static site is written to `_site/`.
